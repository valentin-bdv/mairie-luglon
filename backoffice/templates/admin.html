Nouvelle actualité

Chaque catégorie montre ses {{ en_une }} actualités les plus proches dans le temps sur la page Actualités. Les suivantes restent atteignables en faisant défiler, et sur la page de leur catégorie.

Une date à venir affiche « À venir », une date passée affiche « Terminé ».

Les polices et les couleurs sont celles du site : c'est ce qui évite qu'une publication à l'autre le site parte dans tous les sens.

Nouveau document

Fichiers PDF uniquement, 20 Mo maximum. Le document apparaît immédiatement dans sa catégorie sur la page « Arrêtés et publications ».

Le fichier ne peut pas être remplacé après coup : pour changer le PDF, supprimez le document et redéposez-le.
