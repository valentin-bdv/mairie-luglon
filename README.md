# Mairie de Luglon - Site Officiel

Ce projet est le site web officiel de la Mairie de Luglon (Landes, 40630).

## Structure du projet

- `index.html` : Page d'accueil du site présentant les informations de la mairie, les horaires d'ouverture, les démarches en ligne, les actualités et le contact.
- `README.md` : Documentation du projet.

## Fonctionnalités

- Présentation de la commune de Luglon.
- Affichage des horaires d'ouverture de la mairie.
- Accès rapide aux démarches administratives.
- Informations sur les actualités locales.
- Coordonnées de contact et adresse.
